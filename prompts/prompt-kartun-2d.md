# Prompt: Tukar clip jadi kartun 2D (pergerakan sama)

Copy prompt bawah ni, upload clip kau ke Claude, lepas tu paste.

```
Turn this raw clip into a full 2D cartoon animation. Preserve the original audio as closely as the tool allows, including every word, laugh, pause, and its timing. Rebuild the visuals as animation.

STYLE
Flat 2D vector cartoon. Thick dark outlines, solid colour fills, minimal shading. Simple puppet-rig characters with big round expressive eyes and clean shapes. Use a 9:16 vertical format.

CHARACTERS
Analyse the whole clip and identify every person on screen. Turn each into a recognisable cartoon version, preserving hairstyle, facial hair, skin tone, glasses, outfit patterns and colours, accessories, and props such as microphones, bottles, and papers. Keep each character's appearance consistent across every shot.

LIP SYNC AND PERFORMANCE
Sync each character's mouth to their own voice as closely as possible. Keep a character's mouth closed when they are not speaking. Recreate the performance: head turns, hand gestures, pointing, leaning, laughing, eye rolls, and surprised expressions. Match the timing of every movement to the original clip, frame by frame (use pose tracking / motion capture on the original if possible).

SCENES AND CAMERA
Keep the same shot order, cuts and framing as the original. Redraw each background as a simple flat cartoon version of the real location.

OUTPUT
A 9:16 MP4 with the original audio. Show me a frame-by-frame storyboard first, then render.
```
