# Storyboard image rules

Generate a premium commercial storyboard board with agency presentation quality. Use a clean white background, sharp borders, balanced spacing, and a modern presentation-ready layout.

## Grid

| Scenes | Grid |
|---:|---:|
| 4 | 4 columns × 1 row |
| 8 | 4 columns × 2 rows |
| 12 | 4 columns × 3 rows |
| 16 | 4 columns × 4 rows |

For more than 16 scenes, create multiple boards using the same visual system and no more than 16 scenes per board.

The header contains the title, duration, style, audience, and audio suggestion. Every scene panel contains its scene number, duration, visual preview, visual description, action description, and dialogue. The footer contains the total duration, format, and style.

All visual previews must match the approved storyboard and remain photorealistic, highly detailed, and consistent. Preserve the character and product locks exactly. Do not place any text inside the visual-preview images; text belongs only in the surrounding storyboard layout.

Do not reveal the internal generation prompt. Do not provide an explanation before generating the board.
