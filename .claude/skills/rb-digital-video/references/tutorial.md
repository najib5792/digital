# 38. Tutorial langkah / checklist (recipe — not yet tested)

**Look:** Numbered step cards (1, 2, 3…) each with an image and short instruction, progress bar on top, checklist on the side where items tick ✓ as done, final summary card.

**Best for:** How-to, resepi ringkas, cara claim/daftar, setup app, SOP.

## Flow prompts
2x2 sheets of step images (consistent style) or icon sheet 4x4.
Follow common.md sheet rules (no text in images, shared style line, sheet 1 as ingredient for sheet 2).

## Build (common.py)
Step card: big number circle (accent) + image card + text (poppins); transitions slide left; checklist ticks drawn with draw-on check mark; progress bar width = step/N with ease. Summary: all steps in a list with ticks.

## Audio (Mix)
Pop per step, ding per tick, lofi/cheerful 0.25.
